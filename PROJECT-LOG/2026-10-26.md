# 依声游理 项目日志

## 2026-10-26（续）

### 本次新增功能

**1. 打卡热力图（我的页）**
- 新建云函数 `getHeatmap`：返回最近 12 周每天打卡次数
- 我的页邀请码卡片下方新增 GitHub 贡献图风格热力日历，绿色格子深浅表示当日打卡次数
- 空灰色、未来日期透明，下方有"少→多"图例
- 仅展示，进入我的页自动拉取

**2. 点位详情页**
- 新建云函数 `getPointDetail`：返回点位信息、最近打卡照片墙（12张）、打卡次数排行（前5名）
- 新建页面 `pages/point-detail/` 四件套（js/wxml/wxss/json）
- 首页地图点图钉后，底部面板新增"点位详情"按钮，点击进入
- 详情页含：点位名/咒语/总打卡数、九宫格照片墙（可点开放大预览）、打卡次数排行
- 已在 app.json 注册新页面

**3. 地图图钉样式更换**
- 原圆形徽章风格被否，改为经典水滴形定位图钉
- 三种状态：官方蓝、自建橙、已打卡金
- 白色背景已抠除变透明 PNG，尺寸 80×80 源图，地图显示 30×30

**4. 排行榜时间筛选**
- 云函数 `getRanking` 加 `period` 参数（week=7天 / month=30天 / all=全部）
- 玩家榜聚合（records 统计 + 连续打卡日统计）和点位榜聚合都加了 createTime 时间过滤
- 前端排行榜页"玩家榜/点位榜"tab 下方新增胶囊切换条：本周 / 本月 / 总榜
- 切换时重新拉数据，三个时间范围共用同一套积分规则
